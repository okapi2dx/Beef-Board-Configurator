# Beef Board Configurator

> **このプロジェクトは [HWXLR8/beef-board](https://github.com/HWXLR8/beef-board) をベースに開発しているフォーク／派生プロジェクトです。**  
> オリジナルのBEEF BOARDを基盤として、Windowsデスクトップ版Configuratorや各種設定・診断機能、ファームウェアの拡張を行っています。

**Beef Board Configurator** は、BEEF BOARDを使用した音楽ゲーム向けコントローラーの設定・調整・診断・ファームウェア更新を、Windows上でまとめて行うためのデスクトップアプリケーションです。

従来のブラウザベースの設定画面をWindowsデスクトップアプリとして統合し、BEEF BOARDをUSB接続するだけで各種設定を変更できます。

主にIIDX系コントローラーでの使用を想定しており、細かな入力調整からLEDカスタマイズ、動作確認、ファームウェア更新まで、コントローラーのセットアップに必要な機能を1つのアプリにまとめています。

## AI Development

本プロジェクトは、**設計・実装・デバッグ・ドキュメント作成を含め、すべてAIを活用して開発しています。**

仕様決定や実機での動作確認は人間が行い、コード作成や修正はAIを中心に進めています。

## アプリケーション

Windows用のポータブルアプリとして動作し、通常使用ではブラウザ・Node.js・Pythonなどの追加インストールは必要ありません。

BEEF BOARDとUSB接続し、アプリから直接設定を読み込み・変更できます。

### 主な機能

- **入力設定**
  - Default / IIDX Entry / IIDX Premium モード
  - Joystick / Keyboard入力切り替え
  - アナログ / デジタルターンテーブル対応
  - ターンテーブル回転方向反転
  - 感度調整
  - デッドゾーン調整
  - 入力保持時間調整
  - 入力ディレイ調整
  - ターンテーブル入力特性の調整
  - ボタンのチャタリング防止設定

- **LED設定**
  - ボタンLED設定
  - ターンテーブルLED設定
  - ライトバーLED設定
  - LEDカラー変更
  - 各種ライティングエフェクト
  - 明るさ調整
  - フェード時間調整
  - LED点灯反転
  - ボタンごとの個別LED設定

- **キー割り当て**
  - キーボード入力時のキー割り当て変更
  - 物理ボタンと論理ボタンの配置変更
  - コントローラーに合わせた自由なボタン配置

- **コントローラーモニター**
  - ボタン入力状態をリアルタイム表示
  - ターンテーブル入力状態の確認
  - コントローラーから送信される診断情報の表示
  - 入力調整やトラブルシューティングを実機を見ながら確認可能

- **ファームウェア更新**
  - BEEF BOARD用HEXファイルの書き込み
  - AT90USB1286 DFUモード対応
  - avrdudeをアプリに内蔵
  - HEXファイル検証
  - 書き込みログ・結果表示
  - Pythonや旧beef-toolを別途起動せずにファームウェア更新可能

- **その他**
  - 接続状態表示
  - 現在のファームウェアバージョン表示
  - アプリ更新確認
  - 日本語 / English切り替え
  - ライト / ダークテーマ対応

設定変更はBEEF BOARDへ送信され、対応する設定は基板側のEEPROMへ保存されるため、PCやアプリを終了した後も設定を保持できます。

# Firmware

本リポジトリには、Beef Board Configuratorと連携する**BEEF BOARD用ファームウェア**も含まれています。

ファームウェアは **AT90USB1286 / 16 MHz** を対象とし、LUFAを利用したUSB HIDデバイスとして動作します。

コンフィグアプリとの通信にもUSB HIDを使用しており、通常のゲームコントローラーとして動作しながら、PC側から設定変更や診断情報の取得を行うことができます。

### 主な機能

- AT90USB1286対応
- USB HIDによる低遅延入力
- Joystick / Keyboard入力対応
- IIDX向けUSBデバイスモード
- 最大11ボタン入力
- アナログターンテーブル対応
- デジタルターンテーブル対応
- ターンテーブル回転方向反転
- 感度調整
- 時間式デッドゾーン
- 入力保持時間
- 入力ディレイ
- ターンテーブル入力特性調整
- ボタンデバウンス
- 物理ボタン配置のリマッピング
- ボタンLED PWM制御
- LED明るさ・フェード・反転設定
- ボタンごとの個別LED設定
- RGBターンテーブルLED制御
- RGBライトバー制御
- 複数のLEDエフェクト
- EEPROMへの設定保存
- USB HID経由の設定読み書き
- リアルタイム診断データ送信
- ファームウェアバージョン取得
- USB経由でDFUブートローダーへ移行
- B1 + B2を押しながら起動するDFUモード

ファームウェアとConfiguratorは共通の設定データを使用しており、アプリから変更した入力・LED・キー割り当てなどの設定を基板へ直接反映できます。

これにより、ファームウェアを書き換えることなく、コントローラーの操作感やLED動作をユーザーごとに調整できます。

## Project Goal

Beef Board Configuratorの目的は、BEEF BOARDの設定をできるだけ簡単にしながら、音楽ゲーム用コントローラーで必要となる細かな調整機能も提供することです。

**接続 → 設定 → テスト → ファームウェア更新**

までを1つのWindowsアプリで完結できる環境を目指しています。
