# Beef Board Configurator v1.2.0

Windows x64用。ファームウェア更新に旧beef-tool同梱のavrdude 7.1を内蔵しました。通常の設定画面はこれまでどおりHIDで接続します。デスクトップ版のファームウェア更新ではWebUSBを使用しません。

## 書き込み手順

1. v1.2.0のEXEを起動し、Firmwareタブを開きます。
2. 「HEXファイルを選択」でBEEF BOARD用の.hexを選びます。
3. 通常接続できる場合は「接続中の基板を書き込みモードにする」を押します。すでにDFUモードなら不要です。通常接続できない場合はB1+B2を押しながらUSBを接続します。
4. 対象の基板だけが接続されていることを確認し、「書き込み開始」→「このファイルを書き込む」を押します。
5. 書き込み・照合の完了後、USBを抜き差しして通常モードに戻します。

ファイル名をbeef.hexに変更する必要はありません。選択時にチェックサムなどを検査し、その時点の内容を一時ファイルとして書き込みます。実行ログが画面に表示されます。書き込み中はアプリの終了を防止します。

## ドライバー

旧beef-toolのavrdude/flip1方式を使用します。従来beef-toolで動作していたDFUドライバー環境を利用してください。リポジトリの旧ドライバー設定は03EB:2FFBにlibusb-win32を指定しています。WinUSBへ変更した場合、そのまま動くとは限りません。接続失敗時はログ全文を確認してください。

ドライバーの自動インストール・変更は行いません。変更する場合はDFU機器（03EB:2FFB）に限定し、通常のBEEF BOARD HID機器のドライバーを変更しないでください。

## 変更と検証

- avrdude.exeとavrdude.confをEXE内に同梱。Pythonやbeef-tool別起動は不要。
- flip1 / usb1286 / flash:w:firmware.hex:i を使用。照合を無効化する-Vや署名チェックを省略する-Fは付けません。
- HEXチェックサム・アドレス・終了レコード・重複の検査、選択後の内容固定、同時書き込み防止、実行ログと終了コード表示。
- WebUSB版にあった64 KiBの制限ではなく、ネイティブ版はAT90USB1286の128 KiBアドレス範囲を検査します。すべてのHEXの互換性を保証するものではありません。
- デスクトップ用は既存のSvelte画面を直接ビルドし、Webサーバーを同梱しません。
- UIビルド成功。6件の自動テスト成功（HEX検査、固定した内容と引数、同時実行拒否、失敗結果、一時ファイルの後片付け、既存機器許可・DFU分割）。元のSliderInputに警告2件が残っています。
- この版の実機書き込み・ドライバー互換性は未検証です。

## ソースから作成

beef-configとdesktopの各フォルダーでnpm ciを実行し、desktopでnpm test、npm run distを実行します。今回の依存パッケージは取得済みのものを使用しています。上流リポジトリのGPL-3.0のLICENSEを同梱しています。再配布する場合は対応ソースも提供してください。
